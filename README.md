# 🌳 Durian Smart Garden - ระบบบันทึกและจัดการสวนทุเรียนอัจฉริยะ

เว็บแอปพลิเคชันจัดการสวนทุเรียนสไตล์โมเดิร์น (Modern Soft Blue Palette) ช่วยชาวสวนวางแผนขั้นตอนการทำงาน, จัดการปัจจัยการผลิตและอุปกรณ์, บันทึกบัญชีรายรับ-รายจ่าย, ตรวจเช็กสภาพอากาศเฉพาะจุดด้วย **Open-Meteo API & Google Maps**, และสำรองข้อมูลซิงค์กับ **Google Sheets** ผ่าน **Google Apps Script**

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **🌳 จัดการแปลงสวนทุเรียนหลายแปลง**: เพิ่ม ลบ สลับแปลง และดูภาพรวมงานคงค้างของแต่ละแปลง
2. **⛅ ตรวจเช็กสภาพอากาศเฉพาะสวน (Open-Meteo API & Google Maps)**:
   - สภาพอากาศ Real-time (อุณหภูมิ, ความชื้น, ความเร็วลม, ปริมาณฝน)
   - พยากรณ์อากาศล่วงหน้า 1 วัน และ 2 วัน
   - 💡 คำแนะนำดูแลทุเรียนอัตโนมัติ (เช่น เตือนงดพ่นยาเมื่อฝนจะตก, เตือนเช็กเชือกโยงกิ่งเมื่อลมแรง)
   - รองรับการปักหมุดด้วยพิกัด GPS, ลิงก์ Google Maps หรือตำแหน่งปัจจุบัน
3. **📝 ขั้นตอนการทำงาน (Tasks)**: บันทึกงานรายวัน ปรับสถานะงาน (ยังไม่ทำ / กำลังทำ / เสร็จแล้ว) พร้อมระบบประวัติงาน
4. **📦 สิ่งที่มีไว้ใช้ในสวน (Supplies & Equipment)**:
   - แยกหมวดหมู่ชัดเจน: **🍃 ปุ๋ย**, **🛠️ อุปกรณ์**, **🚰 ท่อ**, **🧪 ยา**
   - ปุ่มแท็บตัวกรองหมวดหมู่ด่วน พร้อมตัวเลขบอกจำนวนสิ่งของ
   - ปุ่ม **"ของหมด"** สำหรับขีดฆ่าเตือนให้เติมสิ่งของ
5. **💰 บัญชีรายรับ - รายจ่าย**: สรุปกำไร/ขาดทุนสุทธิ แยกตามแปลงสวน
6. **📊 ซิงค์ข้อมูลกับ Google Sheets**: สำรองข้อมูลขึ้น Cloud และกู้คืนข้อมูลได้ง่ายๆ ผ่าน Google Apps Script

---

## 📊 วิธีเชื่อมต่อระบบกับ Google Sheets ผ่าน Google Apps Script

คุณสามารถสำรองข้อมูลทั้งหมดในเว็บแอปขึ้น **Google Sheets** เพื่อเปิดดูเป็นตาราง หรือดึงข้อมูลกลับมาใช้งานบนเครื่องอื่นได้ง่ายๆ ตามขั้นตอนดังนี้:

### 📌 ขั้นตอนที่ 1: สร้าง Google Sheets และเปิด Apps Script
1. เข้าไปที่ [https://sheets.new](https://sheets.new) เพื่อสร้างไฟล์ Google Sheets ใหม่ขึ้นมา 1 ไฟล์
2. ตั้งชื่อไฟล์ Google Sheets ตามต้องการ เช่น *"บันทึกข้อมูลสวนทุเรียน"*
3. ที่เมนูด้านบน คลิกที่ **"ส่วนขยาย" (Extensions)** > เลือก **"Apps Script"**

---

### 📌 ขั้นตอนที่ 2: วางโค้ด Google Apps Script
1. ในหน้าต่าง Apps Script จะมีไฟล์ชื่อ `Code.gs` ให้**ลบโค้ดเดิมที่มีอยู่ออกทั้งหมด**
2. เปิดไฟล์ [`google-apps-script.js`](./google-apps-script.js) ในโปรเจกต์นี้ หรือกดปุ่ม *"คัดลอกโค้ดทั้งหมด"* จากหน้าต่างในเว็บ
3. นำโค้ดทั้งหมดมาวางลงใน `Code.gs`
4. กดปุ่ม **บันทึก 💾** (หรือกดคีย์ลัด `Ctrl + S` บน Windows หรือ `Cmd + S` บน Mac)

---

### 📌 ขั้นตอนที่ 3: Deploy (ทำให้ใช้งานได้) เป็น Web App
1. คลิกปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้" (Deploy)** ที่มุมบนขวา > เลือก **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. คลิกที่ไอคอนรูปฟันเฟือง ⚙️ ด้านซ้าย > เลือกประเภทเป็น **"เว็บแอป" (Web app)**
3. กำหนดค่าต่างๆ ดังนี้:
   - **คำอธิบาย (Description)**: ใส่ชื่ออะไรก็ได้ เช่น `Durian Garden Sync`
   - **ดำเนินการในฐานะ (Execute as)**: เลือก **`ตัวฉัน (Me)`**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: เลือกเป็น **`ทุกคน (Anyone)`**  
     *(⚠️ จุดนี้สำคัญมาก! ต้องเลือก "ทุกคน (Anyone)" เพื่อให้หน้าเว็บส่งข้อมูลเข้ามาบันทึกได้โดยไม่ต้องล็อกอินบัญชี Google ซ้ำซ้อน)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขอสิทธิ์ ให้กด **"ให้สิทธิ์เข้าถึง" (Authorize access)** > เลือกบัญชี Google ของคุณ > กด **Advanced (ขั้นสูง)** > กด **Go to ... (unsafe)** > กด **Allow (อนุญาต)**
6. เมื่อ Deploy เสร็จแล้ว คุณจะได้รับ **URL เว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec` ให้กดคัดลอก URL นั้นไว้

---

### 📌 ขั้นตอนที่ 4: นำ URL มาเชื่อมต่อในหน้าเว็บ
1. เปิดหน้าเว็บ **Durian Smart Garden**
2. คลิกที่ปุ่มเขียว **"ซิงค์ Google Sheets"** (แถบเมนูด้านบน)
3. วาง Web App URL ที่คัดลอกมาลงในช่อง **"🔗 Web App URL จาก Google Apps Script"**
4. กดปุ่ม **"บันทึก URL"** (สถานะจะเปลี่ยนเป็น 🟢 เชื่อมต่อแล้ว)

---

### 🚀 การใช้งานปุ่มซิงค์ข้อมูล
- **⬆️ ส่งข้อมูลขึ้น Google Sheets**: กดเพื่อส่งข้อมูลแปลงสวน, ขั้นตอนงาน, ปัจจัยการผลิต และบัญชีการเงินทั้งหมด ไปสร้างเป็นตาราง 4 แท็บใน Google Sheets อัตโนมัติ:
  1. `🌳 แปลงสวนทุเรียน` (สรุปภาพรวมแปลง พิกัด และยอดเงิน)
  2. `📝 ขั้นตอนงานในสวน` (รายละเอียดงานและสถานะ)
  3. `📦 สิ่งที่มีไว้ใช้ในสวน` (รายการสิ่งของ หมวดหมู่ และสถานะของหมด)
  4. `💰 บันทึกการเงิน` (ประวัติรายรับ-รายจ่าย)
- **⬇️ ดึงข้อมูลกลับมาที่เว็บ**: กดเพื่อดึงข้อมูลล่าสุดจาก Google Sheets มาอัปเดตลงในหน้าเว็บ (สะดวกเมื่อย้ายเครื่องหรือต้องการกู้คืนข้อมูล)

## 📱 การติดตั้งลงบนหน้าจอมือถือ (Add to Home Screen)

เว็บแอปนี้รองรับ **PWA (Progressive Web App)** และติดตั้งไอคอนครบทุกขนาดตามมาตรฐานสากล:
- **บน iPhone / iPad (iOS Safari)**:
  1. เปิดหน้าเว็บใน Safari
  2. แตะที่ปุ่มแชร์ **Share (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น ⬆️)** ด้านล่าง
  3. เลื่อนลงมาเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
  4. จะได้ไอคอนโลโก้ `Durian Smart` ขึ้นบนหน้าจอเหมือนแอปพลิเคชันจริง
- **บนมือถือ Android (Chrome)**:
  1. เปิดหน้าเว็บใน Chrome
  2. แตะปุ่มเมนู 3 จุด (⋮) มุมบนขวา
  3. เลือก **"ติดตั้งแอป" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**

## 💻 การเปิดใช้งานในเครื่อง (Local Development)

คุณสามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้ทันที หรือรันผ่าน Local Server:

```bash
# ตัวอย่างการรันด้วย npx serve
npx -y serve -l 3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
